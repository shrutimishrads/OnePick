# OnePick Data Catalogue & Fixtures

## Sourcing & Attribution
- All metadata fields (titles, taglines, synopses, runtimes, genres) are 100% original creative works crafted specifically for the Amazon Developer Hackathon.
- Visual poster artwork consists of deterministic, self-contained SVG portrait posters generated locally in `app/assets/posters/` using abstract geometry and offline self-hosted fonts.
- Zero network calls are made for external images, and no copyrighted films, trademarks, or proprietary streaming service assets are used.
